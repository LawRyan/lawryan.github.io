Automate the repetitive

If a check has to be done the same way every cycle, a person shouldn’t be the one doing it.

  1. The problem Ten trades, seven fields each. Checked by hand, that’s seventy look-ups every cycle, and the next cycle starts from zero.
  2. My approach Write each check once, as a rule. Run every rule across every record. Keep only the exceptions for a person, with the reason attached.
  3. The result Run both and compare. The rules finish before the first row is done by hand.

At work, the same idea
