Inside: L//IOS

An independent project I build outside work. An operating system for insight: three applications that understand the data, say what matters, and show their working.

L//IOS is an independent personal technology project and is not affiliated with or endorsed by RBC Capital Markets.

L//IOS Analyst

Working

Give it files it has never seen. It works out the structure, connects the datasets safely, checks quality, builds the dashboard and investigates what changed. Every number traces back to source rows.

  • Excel, CSV, JSON, Parquet and SQLite, including messy sheets
  • Relationship discovery; joins can never multiply rows
  • Data quality checks with stated methods
  • Plain-language questions answered by deterministic tools

Working
