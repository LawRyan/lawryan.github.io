Privacy Policy

Last updated 8 November 2026

Whose data

The studio connects only to the Tiny Ruckus Club's own TikTok, Instagram and YouTube accounts. It does not collect data about other people, and it has no other users.

What it accesses

With the account owner's permission, the studio reads basic profile information (account name, follower count) and statistics for our own videos (views, likes, comments, shares), and it uploads our own videos (to TikTok as drafts).

Where data is kept

Sign-in tokens and statistics are stored only on the computer running the studio. Nothing is sold, shared with third parties, or used for advertising. This website does not store anything: its sign-in pages only pass the one-time sign-in code back to the studio on the same computer.

Removing access

Access can be removed at any time from the studio (Disconnect) or from each platform's app settings. Stored data can be deleted by deleting the studio's data folder.
